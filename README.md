# Simon Game

A browser recreation of the classic Simon memory game, built with vanilla HTML, CSS, and JavaScript.

This project is mainly a coding practice exercise focused on JavaScript fundamentals and DOM manipulation, using event handling, state management, and DOM querying/updates without any frameworks or libraries.

## Live
[Visit Live Site](https://meisan99.github.io/simon-game-challenge/)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+, no frameworks or libraries)

## How to Play

1. Click anywhere on the page to start.
2. Watch and listen to the sequence of colors that flash.
3. Repeat the sequence by clicking the buttons in the same order.
4. Each round adds one more color to the sequence. Make a mistake and it's game over.
5. Click anywhere to restart.

## Running Locally

Just open [index.html](index.html) in a browser — no build step or server required.
